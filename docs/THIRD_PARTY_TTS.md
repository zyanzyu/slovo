pronunciation works without a network connection. The voice is not a system
TTS voice.

## Local patches to VITS Web

The vendored files live in `src/tts/vendor/`. They are the published minified
distribution with three small behavioral changes:

1. ONNX Runtime and Piper WASM URLs point at the bundled `/tts` paths.
2. `numThreads` is fixed to `1` so WebView does not require cross-origin
   isolation / SharedArrayBuffer.
3. The ONNX `InferenceSession` is cached per voice instead of being recreated
   for every sentence.

The original MIT copyright and license terms continue to apply to the vendored
code; the patches are released under the same MIT terms as this project.

## Runtime files

`public/tts/` is generated by `npm run tts:prepare` and is intentionally not
committed to Git (about 100 MB). Release archives contain it. The preparation
script verifies the model SHA-256 and copies the runtime WASM from the installed
npm packages. `ort-wasm-simd-threaded.wasm` is not shipped because inference is
single-threaded; both SIMD and non-SIMD fallback runtimes are included.
