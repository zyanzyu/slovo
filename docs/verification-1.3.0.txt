HANDWRITING LATENCY
- Benchmark: Playwright WebKit, 390x844 viewport, offline Tesseract path, word ПО.
- Latest full run on this build:
    warm-1: 1490 ms, result ПО
    warm-2:  567 ms, result ПО
- warm-1 includes cold Tesseract worker/model initialization. The first result is
  therefore not millisecond-level.
- Changes in 1.3: 80 ms post-stroke debounce (was 220 ms), retain 700 px image
  width for accuracy, prewarm worker, race online/offline, cancel stale work.
- 600 px and 480 px variants were faster (~437–466 ms) but misread ПО as ПС in
  repeated runs, so they were rejected.
- This is a measurable steady-state improvement, not a millisecond recognizer.
  No claim is made that the Tesseract path reaches millisecond latency.
