TTS
- 1.4.0 does NOT bundle a neural TTS model. APK remains about 17 MB.
- Web/Electron now prefers SpeechSynthesisVoice.localService Russian voices.
- Android now enumerates ru voices and skips voices whose
  isNetworkConnectionRequired() is true; it picks the highest-quality local voice
  and falls back to the system Russian locale result.
- Settings displays the selected voice name and has a test button.
- This container has no Russian voice, so voice naturalness, latency and audio
  output could not be verified here. No claim is made that the output is
  human-sounding or that a specific Piper/Silero model is bundled.
- A 160 MB Piper WASM package or a 50–150 MB neural model was rejected for this
  lightweight APK and for Android-native integration risk.

HANDWRITING
- Unchanged from 1.3.0: 80 ms post-stroke debounce, 700 px image width,
  worker prewarm, online/offline race and stale-work cancellation.
- Measured 1.3.0 steady-state: 567 ms; first cold result: 1490 ms. This is not
  millisecond-level and is reported as such.
