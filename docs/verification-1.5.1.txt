TTS runtime verification (desktop)
----------------------------------
The Russian voice is a genuinely bundled Piper/VITS model; no runtime HTTP
request goes to HuggingFace or a CDN.

Direct Electron test (src/lib/local-tts.ts, 127.0.0.1 Vite/dev page):
- First `speakLocalRussian('привет')`: 6,465 ms including first-time
  model/WASM/session load, AudioContext decode and playback.
  onStart=true, onEnd=true.
- First `synthesizeRussian('привет')` after warm-up: 704 ms, 23,596-byte
  audio/x-wav blob, RIFF/WAVE header.
- Next `synthesizeRussian('здравствуйте')`: 1,030 ms, 45,612-byte
  audio/x-wav blob.
- OPFS cached the model and voice config; the second synthesis did not fetch
  the 63 MB model.
- The ONNX InferenceSession is cached per voice after the first synthesis.
  The WAV cache (120 entries, LRU) makes repeated SRS cards return the same
  blob without running the phonemizer/ONNX again.

Handwriting / OCR boundary
--------------------------
This release does not claim millisecond handwriting recognition. The 1.3
benchmark remains the latest measured result: ~1,490 ms cold and ~567 ms warm
for the offline fallback; 600/480 px downscaling misread "ПО" as "ПС". The
online path can be faster when available, but it is network-dependent. The
1.5 work focused on the bundled TTS and release packaging; handwriting was not
rewritten.

Source assets
-------------
The 63 MB voice and copied WASM files are deliberately gitignored. A clean
checkout must run:
    npm install
    npm run tts:prepare
`tts:prepare` copies Piper/ONNX runtime files from npm and downloads the voice
from the public mirror, verifying SHA-256
8ff38212d23da300bbe3705c645e6e5b9475f0bfde01558eb17813e22acaaaaa.

Known unverified / limitations
-------------------------------
- Android real-device install, first-run 63 MB asset streaming, WebView audio
  and OPFS cache.
- Windows real-machine start.
- Linux x64 real-machine start.
- Subjective naturalness / "human-likeness" of the Irina voice; no listening
  hardware in the build container.
